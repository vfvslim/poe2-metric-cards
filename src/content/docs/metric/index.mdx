## How to read a card

Every card follows the same order: **业务问题** (the question it answers), **指标定义**,
**计算公式**, **分子 / 分母**, **粒度**, **过滤条件**, **维度**, **踩坑与注意**, **SQL 模式**,
then a machine-readable **YAML** block for the data agent.

The status pill at the top of each card says how much to trust it — `draft` means
written from SQL but not signed off, `stubbed` means the logic is not implemented.
